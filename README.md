# Paisabazaar-Banking-Fraud-Analysis-Using-Python
📊 Credit Score Analysis using Python<br>

📌 Project Overview

This project focuses on analyzing customer financial and behavioral data to understand the factors that influence credit score classification. The analysis was performed using Exploratory Data Analysis (EDA) techniques and data visualization libraries in Python.

The dataset contains customer-related financial information such as annual income, outstanding debt, payment delays, EMI burden, credit utilization ratio, number of loans, and payment behavior. The main goal of the project is to identify patterns associated with different credit score categories (Good, Standard, and Poor) and generate meaningful business insights that can support better credit risk assessment.

🎯 Problem Statement

Financial institutions rely heavily on credit scores to evaluate the creditworthiness of customers before approving loans and other financial products. However, customer financial behavior is influenced by multiple factors such as debt, repayment habits, income, and credit usage patterns.

This project aims to analyze customer financial data to identify the major factors affecting credit score classification and understand how financial behavior impacts customer creditworthiness.

🏢 Business Objective

The objective of this project is to help financial institutions improve their credit risk assessment process through data-driven insights. By analyzing customer financial behavior, the project helps identify financially risky customers, understand repayment patterns, and support better lending decisions.

The insights generated can help:

Reduce the risk of loan defaults
Improve customer segmentation
Support personalized financial product recommendations
Enhance decision-making in credit management<br>

📊 Key Insights<br>
* Customers with high outstanding debt were more likely to have poor credit scores.<br>
* Frequent payment delays strongly affected customer creditworthiness.<br>
* High credit utilization ratios indicated financially risky behavior.<br>
* Customers with stable income and disciplined repayment behavior generally maintained good credit scores.<br>
* Multiple active loans and heavy EMI burdens were associated with financial stress.<br>
